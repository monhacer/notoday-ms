# notoday-ms

**notoday-ms** یک تغییر ساده در رجیستری ویندوز است که باعث می‌شود آپدیت‌های خودکار ویندوز اجرا نشوند و بتوانید آپدیت‌ها را برای مدت خیلی طولانی (حدود ۲۰ سال) Pause کنید.

اگر دوست ندارید ویندوز بدون اجازه آپدیت شود، این ابزار برای شماست.

---

## این پروژه چه کاری انجام می‌دهد؟

این پروژه دو کار اصلی می‌کند:

1. **افزایش مدت Pause آپدیت‌ها**
   - از چند هفته
   - به حدود **۷۳۰۰ روز (تقریباً ۲۰ سال)**

2. **غیرفعال کردن آپدیت خودکار ویندوز**
   - دانلود خودکار انجام نمی‌شود
   - ری‌استارت ناگهانی ندارید
   - آپدیت وسط کار مزاحم نمی‌شود

---

## چطور کار می‌کند؟

فایل رجیستری این تنظیمات را تغییر می‌دهد:

- `FlightSettingsMaxPauseDays`  
  اجازه می‌دهد آپدیت‌های ویندوز برای مدت خیلی طولانی Pause شوند.

- `NoAutoUpdate`  
  آپدیت خودکار ویندوز را غیرفعال می‌کند.

آپدیت ویندوز حذف یا خراب نمی‌شود، فقط به صورت خودکار اجرا نمی‌شود.

---

## نصب

1. پروژه را دانلود یا Clone کنید
2. روی فایل `justclickme.reg` دوبار کلیک کنید  
   یا Right Click → **Run as administrator**
3. پیام Registry را تأیید کنید
4. بهتر است یک بار ویندوز را ری‌استارت کنید

برای فعال شدن Pause:
- `Settings → Windows Update → Pause updates`

---

## آیا هنوز می‌توانم آپدیت کنم؟

بله.

- آپدیت دستی همچنان امکان‌پذیر است
- Microsoft Store معمولاً بدون مشکل کار می‌کند
- Windows Defender ممکن است آپدیت امنیتی بگیرد

کنترل آپدیت‌ها دست خودتان است.

---

## نکات مهم

- بهترین نتیجه روی **Windows Pro / Enterprise**
- بعضی آپدیت‌های بزرگ ممکن است تنظیمات را برگردانند
- ممکن است در نسخه‌های آینده ویندوز کار نکند
- استفاده با مسئولیت خودتان است

---

## بازگرداندن تنظیمات (Undo)

اگر خواستید همه چیز به حالت قبل برگردد:

1. فایل **`undo.reg`** را دانلود کنید
2. آن را اجرا کنید
3. سیستم را ری‌استارت کنید

تمام.

---

## چرا این پروژه ساخته شده؟

برای کسانی که:
- از آپدیت اجباری خوششان نمی‌آید
- می‌خواهند کنترل سیستم دست خودشان باشد
- ترجیح می‌دهند زمان آپدیت را خودشان انتخاب کنند
