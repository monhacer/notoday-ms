# notoday-ms 😌🛑

> _«امروز نه، مایکروسافت. امروز نه.»_

**notoday-ms** یک تغییر کوچک، ساده و بی‌دردسر در رجیستری ویندوز است که با احترام (و البته سماجت) به Windows Update می‌گوید:
**برو یک مرخصی خیلی خیلی طولانی بگیر** — حدود ۲۰ سال.

چون بعضی وقت‌ها… فقط دلت می‌خواهد سیستم‌عاملت ریلکس باشد.

---

## 🧠 این پروژه چه کاری انجام می‌دهد؟

این پروژه دو تغییر ساده در رجیستری ویندوز اعمال می‌کند:

1. **افزایش حداکثر زمان Pause آپدیت‌ها**
   - از «چند هفته»
   - به **حدود ۷۳۰۰ روز (تقریباً ۲۰ سال)**

2. **غیرفعال کردن آپدیت خودکار از طریق Group Policy**
   - بدون دانلود ناگهانی
   - بدون ری‌استارت‌های اعصاب‌خردکن
   - بدون «Updating… 30%» در بدترین لحظهٔ ممکن

---

## 🔧 چطور کار می‌کند؟

فایل رجیستری این کلیدها را تغییر می‌دهد:

- `FlightSettingsMaxPauseDays`  
  اجازه می‌دهد Windows Update برای مدت زمانی کاملاً غیرمنطقی Pause شود.

- `NoAutoUpdate`  
  رفتار آپدیت خودکار را در کل سیستم غیرفعال می‌کند.

Windows Update نابود نمی‌شود — فقط…  
**مودبانه نادیده گرفته می‌شود.**

---

## 📦 نصب

1. ریپازیتوری را دانلود یا Clone کنید
2. روی فایل `justclickme.reg` دوبار کلیک کنید  
   - یا Right Click → **Run as administrator**
3. در پیغام Registry روی **Yes** کلیک کنید  
   (درست تصمیم گرفته‌اید)
4. (اختیاری ولی پیشنهاد می‌شود) ویندوز را ری‌استارت کنید

برای فعال شدن Pause:
- `Settings → Windows Update → Pause updates`

و حالا از Pause بیست‌ساله لذت ببرید.

---

## 🔄 آیا هنوز می‌توانم دستی آپدیت کنم؟

بله.  
الان کنترل دست خودتان است.

- آپدیت دستی همچنان ممکن است
- Microsoft Store معمولاً کار می‌کند
- Windows Defender ممکن است آپدیت‌های امنیتی بگیرد

این پروژه **هرج‌ومرج خودکار** را متوقف می‌کند، نه آزادی شما را.

---

## ⚠️ نکات مهم

- بهترین عملکرد روی **Windows Pro / Enterprise**
- Feature Updateها ممکن است Policyها را ریست کنند (ممنون مایکروسافت)
- نسخه‌های آیندهٔ ویندوز ممکن است این روش را نادیده بگیرند
- استفاده با مسئولیت خودتان — خراب شد، مال خودتان است

---

## 🔙 بازگردانی / Undo آپدیت‌ها

نظرتان عوض شد؟  
مایکروسافت برنده شد؟ اشکالی ندارد.

برای بازگرداندن همه چیز به حالت پیش‌فرض:

1. فایل **`undo.reg`** را دانلود کنید
2. آن را اجرا کنید (دوبار کلیک یا Run as administrator)
3. پیغام Registry را تأیید کنید
4. ویندوز را ری‌استارت کنید

تمام شد. بدون دردسر.

---

## 🤡 چرا این پروژه وجود دارد؟

چون:
- آپدیت اجباری آزاردهنده است
- «Restart required» بیشتر شبیه تهدید است
- کنترل باید دست کاربر باشد

**notoday-ms** از ویندوز متنفر نیست.  
فقط حد و مرز تعیین می‌کند.
